# Aven brand kit — "Envol"

An origami bird folded from six colour facets, flying up and to the right: an idea taking flight. Built by `build-envol.mjs` (run `npm run brand`).

## Files (`final/`)

| File | Use |
|---|---|
| `aven-symbol.svg` | Primary symbol, full colour, transparent |
| `aven-symbol-black.svg` / `aven-symbol-white.svg` | One-colour symbol (tints of a single colour keep the folds readable) |
| `aven-horizontal-light.svg` / `aven-horizontal-dark.svg` | Symbol + wordmark for light / dark backgrounds |
| `aven-horizontal-black.svg` / `aven-horizontal-white.svg` | One-colour lockups |
| `aven-wordmark-light.svg` / `aven-wordmark-dark.svg` | Wordmark alone |
| `aven-app-icon.svg` / `aven-app-icon-light.svg` | App icon on ink / paper tile |
| `png/` | Rendered PNGs (1024 px icon, 1600 px lockups) |
| `../src-tauri/icons/icon.ico` and PNGs | Windows icon set generated from the app icon |
| `../src-tauri/installer/*.bmp` | Installer header and sidebar art |

## Typography

- Wordmark: custom lowercase "aven" built from round-capped strokes (x-height 100, stroke 22 on a 256 grid). Do not retype it in a font.
- Interface: Figtree (UI text), Bricolage Grotesque (display headings). Both SIL OFL.

## Usage

- Clear space: at least the height of the bird's head facet on every side.
- Minimum size: symbol 16 px (favicon), lockup 96 px wide.
- On photos or busy backgrounds use the app-icon tile, not the bare symbol.
- Do not recolour individual facets, add outlines, shadows or gradients, rotate the bird, or rearrange the lockup.

## Exploration history

`concepts/` (monogram A, rejected as too corporate), `concepts2/` (overlapping primitives, rejected), `concepts3/` (four non-letter directions: L'Aven shaft, Pont-Aven cloisonné, lifted canvas, origami bird). The user chose the origami bird.
